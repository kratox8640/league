# 곡선중 2026 스포츠 축제 기록 프로그램

첨부된 2026 운영 계획서의 9개 종목, 배점, 시간표를 반영한 체육대회 기록 사이트입니다. 기존 스포츠클럽 리그와 별도로 동작합니다. 실제 경기 결과나 학생 개인정보는 초기 데이터에 포함하지 않습니다.

## 기능

- 1~3학년 각 3개 반, 9개 종목, 총 27개 학년별 결과 입력
- 임시 저장과 결과 확정 구분. 확정된 결과만 종합점수에 합산
- 줄다리기 3전2선승 예선·결승 승수에서 최종 순위 계산
- 횟수·심사 합계는 큰 기록 우선, 시간은 작은 기록 우선으로 순위 계산. 동률이면 심판 최종 판정 필요
- 종합 동점은 줄다리기 순위 우선, 미확정 또는 그 순위도 같으면 공동순위
- 전체 현황, 학년별 순위, 문서 기준 타임테이블, 경기 규정
- JSON 백업·기기 내 복원, CSV 결과, 인쇄
- Google Sheets 연결 시 다른 기기 공유, 서버 비밀번호 확인, 같은 결과의 동시 수정 충돌 감지
- 시트 연결 전에는 이 브라우저에만 저장. 실제 Google Sheets 연결/배포는 별도 설정 필요

## Google Sheets 처음 연결

1. 새 Google 스프레드시트를 만듭니다. 기존 리그 시트와 별도로 만드세요.
2. 확장 프로그램 → Apps Script를 열고 apps-script/Code.gs를 붙여 넣습니다.
3. 준비된 시트에서는 연결설정 탭 B3의 선생님 비밀번호를 사용합니다. setup()이 이 값을 ADMIN_TOKEN 서버 속성에 설정합니다. 연결설정 탭이 없으면 스크립트 속성을 직접 지정할 수 있습니다. 비밀번호를 소스나 GitHub에 넣지 마세요.
4. setup() 함수를 한 번 실행하고 권한을 허용합니다. 체육대회기록 시트가 생성됩니다.
5. 배포 → 새 배포 → 웹 앱. 실행 사용자는 나, 접근은 모든 사용자로 설정합니다. 학교 정책이 이를 막으면 관리자 확인이 필요합니다.
6. /exec 주소를 사이트의 연결·백업 → 시트 연결에 붙여 넣습니다.
7. 선생님 로그인에서 같은 비밀번호를 입력합니다. 로그인은 서버에서 확인하며 기록을 쓰지 않습니다.
8. 점수 입력 → 결과 확정 후 성공 메시지와 시트 행을 확인하세요. 실제 저장은 새 웹 앱 배포 후 직접 확인해야 합니다.

### 여러 기기에서 사용

연결·백업 → 다른 기기용 연결 주소 복사를 이용하세요. URL에는 공개 API 주소만 포함되며 비밀번호는 포함되지 않습니다. 각 기기에서 선생님 비밀번호로 로그인합니다. 조회는 30초마다 갱신됩니다. 사이트 자체가 소유자 전용으로 배포된 경우 다른 기기에서도 소유자 계정으로 접속해야 합니다. 학생·다른 교사 공개는 호스팅 접근 설정에서 별도로 허용해야 합니다.

모든 방문자에게 같은 시트를 기본 연결하려면 dist/connection.json의 endpoint에 웹 앱 주소를 넣고 다시 배포하세요. Google Sheets 주소는 API 응답에서 받아 사이트의 연결된 구글 시트 열기 버튼으로 표시합니다.

### Google Sheets 저장 형식

문서키, 학년, 종목, 상태, 반별 순위·기록·점수, 버전, 원본 JSON, 수정 시각을 한 행에 저장합니다. JSON 열과 버전은 동시 수정 확인에 사용되므로 직접 바꾸지 마세요. Apps Script는 문서 잠금과 버전 검사를 수행해 다른 기기 결과를 조용히 덮어쓰지 않습니다. 서버는 순위와 배점을 다시 검증합니다.

Google 로그인이나 계정 초대 없이 쓰는 공개 웹 앱이므로 학생 이름·연락처 등 개인정보는 기록하지 마세요. 서버 비밀번호는 이 창의 메모리에만 유지합니다.

## 배포

빌드 없는 정적 사이트입니다. dist/ 폴더 전체를 웹 호스팅에 올리면 됩니다. GitHub Pages에서는 dist의 내용을 저장소 루트 또는 별도 sports-festival/ 폴더에 올릴 수 있습니다. 소스 전체를 Pages로 배포하려면 Pages의 폴더를 맞추거나 dist/를 배포하는 Actions 워크플로를 사용하세요. 이 대화에서는 기존 GitHub 저장소의 sports-festival/ 폴더에도 정적 파일과 연동 코드를 추가합니다.

## 운영 계획서 확인 사항

- 좌석표·대진표에 맞춰 학년마다 3개 반을 적용했습니다. 응원전·계주의 일부 문장에 4반 표기가 있어 확인이 필요합니다.
- 2인3각은 본문 14명과 참가명단 16명이 달라 인원 표시를 확정하지 않았습니다.
- 목록의 장애물 달리기는 배점표·시간표의 미션 달리기로 통일했습니다.
- 태풍의 눈의 시간 구간과 소요 시간이 다릅니다. 시간 구간을 사용합니다.
- 점심과 공연 시간은 문서대로 겹칩니다.
- 종합 시상 범위(전체 또는 학년별)는 현장 운영본부가 확인해야 합니다. 화면에서 두 범위를 모두 볼 수 있습니다.
- 응원전 세부 심사 기준과 종목 내 동률 처리 규칙은 문서에 없어 임의로 만들지 않았습니다.

## 검증 범위

배점·순위·동점·기록 변환·줄다리기·저장 서버의 인증/버전 충돌/재요청을 자동 검사합니다. Google 계정 연결 권한이 없어 실제 시트 생성과 Apps Script 배포는 수행하지 않습니다. 관리형 브라우저 QA 도구가 없으면 실제 화면 조작 검증은 생략합니다.

## 준비된 시트

Google 계정의 ChatGPT 폴더에 체육대회 전용 시트가 생성되어 있습니다. 사이트의 준비된 구글 시트 열기와 setup.html을 이용하세요. 시트 생성만으로 Apps Script 배포가 이루어지지는 않습니다. setup() 실행 후 웹 앱을 배포하고 /exec 주소를 열면 사이트 연결 버튼이 나옵니다.
