GOOGLE SHEETS SETUP

시트는 준비됐습니다.
웹 앱 배포를 마무리하세요.

Google 계정에서 직접 실행 권한을 허용해야 하는 단계입니다. 아직 사이트 기록이 시트에 자동 저장되지는 않습니다.

01 / PREPARED SHEET

준비된 시트에서 Apps Script 열기

아래 버튼으로 체육대회 전용 시트를 열고, 위쪽 메뉴의 확장 프로그램 → Apps Script를 선택하세요.

준비된 구글 시트 열기 ↗

기존 스포츠클럽 리그 시트와 별도로 만들었습니다. 선생님 비밀번호는 시트의 연결설정 → B3에 준비되어 있습니다.

02 / COPY & RUN

코드 붙여 넣고 setup 실행

  1. 아래 연동 코드 복사를 누릅니다.
  2. Apps Script 편집기의 기존 기본 코드를 지우고 복사한 코드를 붙여 넣은 뒤 저장합니다.
  3. 상단의 함수 선택에서 setup을 고르고 실행을 누릅니다.
  4. Google에서 요청하는 실행 권한을 확인하고 허용합니다.
코드 파일 받기

코드를 불러오는 중입니다.

복사가 안 되면 코드 직접 선택

setup은 연결설정 B3의 비밀번호를 서버 속성에 설정합니다. 비밀번호를 바꿨을 때도 setup을 다시 실행하세요.

03 / DEPLOY

웹 앱으로 배포

  1. 오른쪽 위 배포 → 새 배포를 누릅니다.
  2. 배포 유형에서 웹 앱을 선택합니다.
  3. 실행 사용자는 나, 액세스 권한은 모든 사용자로 선택하고 배포합니다.
  4. 배포 결과의 /exec로 끝나는 웹 앱 주소를 엽니다.
  5. 나타나는 체육대회 사이트 연결하기를 누른 뒤 사이트에서 선생님 로그인합니다.

학교 계정 정책으로 ‘모든 사용자’가 나오지 않으면 Google Workspace 관리자 확인이 필요합니다. 배포 주소를 이 대화에 보내주시면 사이트의 기본 연결 주소도 적용할 수 있습니다.
