선생님이 기록하기

  1. 리그 화면 아래 선생님 입력 모드를 누릅니다.
  2. 기존 Apps Script에 설정된 관리자 비밀번호를 입력합니다.
  3. 학년과 종목을 고르고 경기를 열어 점수를 입력합니다.
  4. 저장됨 표시를 확인합니다. 학생 화면에는 30초 안에 반영됩니다.

설정에서 CSV·JSON 백업을 받을 수 있습니다. 공용 기기에서는 입력 모드를 끄고 나가세요.

Google Sheets 연결

현재 사이트는 기존 Apps Script 주소로 조회하도록 연결되어 있습니다. 실제 저장에는 해당 관리자 비밀번호가 필요하며, 이 배포에서 실제 쓰기는 검증하지 않았습니다.

새 시트로 옮기려면 Apps Script 코드 받기와 설치 안내 받기를 이용하세요. 시트에서 Apps Script를 열고 코드를 붙인 뒤 ADMIN_TOKEN 속성 지정 → setup() 실행 → 웹 앱 배포 순서입니다.

사이트 코드의 SHEET_API에 새 웹 앱의 /exec 주소를 넣으면 됩니다.

연결이 끊겼다면

저장 상태를 확인하고 연결 복구를 기다리세요. ‘이 기기에 저장 중’은 브라우저 로컬 저장을 뜻하며 다른 기기에는 공유되지 않습니다. JSON 백업을 받아 기록을 보관하세요.
